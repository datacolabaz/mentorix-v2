# Trust and Safety

## Core policies

- Platform-only booking/payment for marketplace protection.
- Clear mentor conduct, confidentiality, anti-harassment and professional-boundary terms.
- No guaranteed jobs, admissions, visas, medical/legal/financial advice unless specifically permitted and qualified.
- No sharing of private contact/payment details before a protected relationship where policy forbids it.
- Copyright and data handling rules for documents, code and application materials.

## Minors

Minor participation requires a product decision and should default to stronger controls:

- verified guardian relationship/consent;
- guardian visibility or approved communication channel;
- no private off-platform contact;
- session recording only with explicit consent and policy;
- mentor safeguarding training/acknowledgement;
- escalation path for abuse or self-harm disclosures;
- data minimization and retention limits.

[FOUNDER DECISION REQUIRED] Decide whether MVP is 18+ only. This is the recommended default because it reduces safety, consent and payout complexity while validating the marketplace.

## Reporting and dispute flow

Any participant can report a mentor, mentee, message, session or review. Report severity: low, medium, high, critical. Critical reports can freeze messaging/payout and notify designated safety admins. Store evidence references, reporter confidentiality, case owner, SLA, action and appeal.

Payment disputes, quality disputes and safety reports are separate case types but can be linked. Support refunds without forcing a user to continue unsafe contact.

## Anti-fraud

- rate-limit account, booking, review and payout actions;
- detect repeated card/account/device patterns;
- require completed delivery before reviews;
- flag reciprocal/duplicate reviews and abnormal rating clusters;
- hold first payouts and high-risk refunds;
- prevent self-booking and connected-account abuse;
- monitor off-platform solicitation and repeated cancellations.

## Reviews

Only a completed, non-reversed session/program milestone creates eligibility. One review per reviewer/delivery. Allow private operational feedback separate from public review. Mentor response is moderated like any other content. Remove only under policy; preserve audit record.

## Access control

Relationship data is private to participants, guardian where allowed, assigned support staff and authorized admins. Mentors cannot browse mentee profiles beyond consented goal context. Admin access is logged and scoped. Attachments use signed URLs and malware/type validation.

## Incident response

Define severity, owner, communication template, evidence preservation and post-incident review. Safety metrics include report rate, response SLA, repeat offender rate, refund/dispute rate and false-positive rate.
